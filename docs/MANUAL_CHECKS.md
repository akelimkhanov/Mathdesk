# Проверка доски перед уроком

Сценарий MVP 2 — выделенная рукопись, preview и вставка формулы — описан
пошагово в [HANDWRITING_MATH.md](HANDWRITING_MATH.md). Демо-provider не является
настоящим AI-распознаванием.

Запуск: `npm ci`, `npm run dev`. Откройте приложение в браузере, создайте новую доску.
На macOS вместо Ctrl используйте Cmd. Сохранение локальное: перед уроком и после него
скачивайте JSON. Распознавание фигур по удержанию работает локально, без AI и сети.

| Функция                             | Как проверить вручную                                                                                                                 | Ожидаемый результат                                                                                          |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Плавное перо                        | Нажмите P, медленно напишите несколько цифр мышью, затем проведите быстрые дуги                                                       | Меньше дрожания; концы штрихов совпадают с местом отпускания; плавные стыки                                  |
| Давление стилуса                    | Пишите совместимым пером с разным нажимом                                                                                             | Толщина меняется вместе с нажимом; мышь использует постоянную толщину                                        |
| Настройки пера                      | При P выберите цвет и толщину в верхней контекстной строке; выберите карандаш/маркер рядом                                            | Следующий штрих использует настройки; дополнительные свойства открываются отдельно                           |
| Space Pan                           | При P удерживайте Space и перетащите доску; отпустите Space                                                                           | Доска перемещается, штрих не создаётся; снова можно писать                                                   |
| Middle Pan                          | При любом инструменте перетащите доску средней кнопкой мыши                                                                           | Только перемещение, без новых объектов и действий Undo                                                       |
| Select Pan                          | Нажмите V, перетащите **пустое** место правой кнопкой; затем попробуйте H                                                             | Правая кнопка перемещает пустую область; H включает инструмент Pan                                           |
| Zoom у курсора                      | Наведите курсор на вершину фигуры и используйте Ctrl+колесо                                                                           | Вершина остаётся под курсором, масштаб меняется плавно; пределы 10–500%                                      |
| Кнопки масштаба                     | Нажмите +, −, 100%, «Показать всё» или F                                                                                              | Плавное изменение; 100% восстанавливает единичный масштаб, Fit центрирует весь материал                      |
| Одиночное / множественное выделение | При V нажмите на объект, затем Shift+клик на другой; повторите Shift+клик                                                             | Выделение дополняется и снимается для отдельного объекта/группы                                              |
| Рамка                               | При V протяните левой кнопкой пустую область вокруг нескольких объектов                                                               | Объекты, пересекающие рамку, выделены                                                                        |
| Лассо                               | Откройте стрелку возле Select, выберите «Лассо», обведите материал                                                                    | Выделение соответствует многоугольнику, а не его прямоугольной рамке; Shift добавляет к выбору               |
| Move / Resize / Rotate              | Перетащите выделенный объект; затем угловую ручку; затем круглую ручку над рамкой                                                     | Перемещение, размер и поворот редактируемы; Shift сохраняет пропорции/привязывает угол                       |
| Свойства объекта                    | Выделите объект и раскройте «Параметры объекта»                                                                                       | Можно задать размеры и угол числом; формула сохраняет LaTeX                                                  |
| Copy / Paste / Duplicate / Delete   | Выделите объекты; Ctrl+C, Ctrl+V, Ctrl+D, Delete                                                                                      | Независимые копии со сдвигом; удаление отменяется через Undo. Копирование объектов работает внутри редактора |
| Group / Ungroup                     | Выделите два объекта и нажмите «Сгруппировать»; кликните на член группы, переместите/поверните/масштабируйте; затем «Разгруппировать» | Члены группы выбираются и трансформируются вместе; копия группы независима; Undo восстанавливает группу      |
| Lock                                | Выделите объект/группу и нажмите замок; попробуйте Move, Delete, ластик и цвет; затем разблокируйте                                   | Заблокированный материал не изменяется; разблокировка тоже отменяется                                        |
| Undo / Redo                         | Создайте штрих, текст (T), формулу (M), фигуру; меняйте цвет, толщину, положение, размер и угол                                       | Ctrl+Z отменяет по одному завершённому действию; Ctrl+Shift+Z возвращает их. Камера не засоряет историю      |
| Линия по удержанию                  | При P проведите почти прямую, **не отпускайте** и остановитесь примерно на 0,5 секунды                                                | Появится подсказка «Прямая»; после отпускания создаётся редактируемый отрезок                                |
| Окружность по удержанию             | Нарисуйте почти замкнутый круг и удерживайте около 0,5 секунды                                                                        | Появится подсказка и аккуратная окружность после отпускания                                                  |
| Прямоугольник по удержанию          | Нарисуйте почти замкнутый прямоугольник и удерживайте около 0,5 секунды                                                               | Появится подсказка и редактируемый прямоугольник, включая повёрнутый                                         |
| Отмена преобразования               | После распознавания нажмите Ctrl+Z, затем ещё раз                                                                                     | Первая отмена возвращает исходный штрих; вторая удаляет штрих; Redo возвращает оба действия                  |
| Отказ от преобразования             | После подсказки продолжите рисование и сразу отпустите; или отпустите обычный штрих без паузы                                         | Остаётся рукопись. Незамкнутые дуги, выраженные эллипсы и каракули не должны превращаться в фигуру           |
| Fullscreen / Presentation           | Нажмите значок презентации; пишите, стирайте, используйте Pan/Undo; нажмите «Выйти из презентации»                                    | Скрыты заголовок и панели; инструменты продолжают работать; выход возвращает редактор                        |
| Browser Fullscreen                  | В презентации нажмите «На весь экран», повторно нажмите для выхода; снова включите и нажмите Esc                                      | Реальный fullscreen браузера; иконка и подпись меняются; выход сохраняет презентацию                         |
| Save / Load                         | Дождитесь «Сохранено локально», вернитесь к списку, обновите страницу и откройте доску                                                | Объекты, стили и группы восстановлены; история Undo относится к текущему открытию                            |
| JSON                                | Скачайте JSON, вернитесь в список и импортируйте файл                                                                                 | Открывается отдельная доска с теми же объектами и группами; исходная доска не перезаписывается               |
| RU/KZ/EN                            | Меняйте язык в заголовке и обновляйте страницу                                                                                        | Переведены инструменты, группы, лассо и подсказки; выбранный язык сохраняется                                |
| Math / KaTeX                        | Нажмите M, вставьте `2+2=5`, затем `\frac{1}{2}+x^2`; отредактируйте двойным кликом                                                   | Математика не исправляется автоматически; формулы рендерятся и редактируются                                 |
| Фигуры                              | Создайте отрезок, стрелку, прямоугольник, эллипс и треугольник из Shapes                                                              | Существующие инструменты работают; Shift задаёт равные стороны                                               |

Если Fullscreen API недоступен, кнопка скрыта; при отказе браузера остаётся презентация внутри окна. Нажим
зависит от устройства и драйвера; автоматические тесты эмулируют события пера и
не заменяют проверку на физическом планшете. Объекты в группе масштабируются
пропорционально, чтобы не искажать повёрнутые фигуры и формулы.
