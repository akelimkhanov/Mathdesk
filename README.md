# Mathdesk · AI Math Board

Рабочая математическая доска для учителя и первый сценарий MVP 2:
выделенная рукопись → recognition provider → preview → обычная формула.
Реальный AI API пока не подключён; используется явно обозначенный локальный demo.
Полный технический план: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
Пошаговая проверка всех инструментов: [docs/MANUAL_CHECKS.md](docs/MANUAL_CHECKS.md).
Распознавание рукописи и подключение API: [docs/HANDWRITING_MATH.md](docs/HANDWRITING_MATH.md).

## Запуск

Node.js 22+ (в облачной среде проверено на Node.js 24) и npm.

```sh
cd /workspace/Mathdesk
npm ci
npm run dev
```

Dev-сервер использует порт 3000. Для production: `npm run build`, затем
`npm start`. Секреты, PostgreSQL и внешние AI API для доски и demo MVP 2 не требуются.
Зависимости фиксируются `package-lock.json`; не отключайте проверку TLS.

## Что работает

- Бесконечная доска: прокрутка, Space+drag, Ctrl/Cmd+wheel, pinch-to-zoom,
  плавные кнопки масштаба (10–500%), F / «Показать всё», minimap на малом масштабе.
  Средняя кнопка всегда перемещает доску; при Select правая кнопка на пустом месте
  перемещает доску, а левая сохраняет выделение рамкой.
- Перо, карандаш, полупрозрачный маркер; Pointer Events, pressure samples,
  адаптивное сглаживание, упрощение точек с сохранением давления и отдельный
  transient canvas для текущего штриха. Удержание около 500 мс распознаёт
  прямую, окружность и прямоугольник без AI; преобразование отменяется отдельно.
- Ластик удаляет целые объекты (не отдельные части штриха).
- Одиночное выделение, Shift+click, выделение прямоугольной областью,
  лассо, перемещение, дублирование, внутреннее копирование/вставка, удаление и
  блокировка. Group/Ungroup сохраняются в JSON; группы перемещаются, вращаются
  и пропорционально масштабируются вместе.
- Изменение размеров через четыре угловые ручки и вращение через ручку над
  рамкой; числовые поля доступны в «Параметры объекта».
- Текст и редактируемые формулы LaTeX с KaTeX; двойной клик открывает редактор.
  Выражение `2+2=5` остаётся неизменным.
- MVP 2: выделите strokes Select/Lasso и нажмите «Распознать как формулу».
  PNG и world samples передаются отдельному MathRecognitionProvider. Preview
  показывает до трёх вариантов и редактируемый LaTeX; при низком confidence
  требуется подтверждение замены. Вставка рядом оставляет рукопись. Оба действия
  отменяются одним Undo, исходные samples сохраняются в MathObject.source.
  Demo возвращает фиксированные примеры, не распознаёт рукопись и не использует сеть.
- Отрезок, стрелка, прямоугольник, эллипс, треугольник; Shift задаёт равные
  стороны. Цвет, заливка, ширина и прозрачность.
- Undo/Redo до 200 операций; одно завершённое перетаскивание — одна операция.
- Dashboard, метаданные урока, IndexedDB autosave, JSON backup/import с проверкой
  формата и лимитом файла 25 МБ. Импорт создаёт отдельную доску, не перезаписывая
  существующую.
- RU/KZ/EN, светлая и тёмная темы, фоны, Fullscreen / Presentation с рабочей
  минимальной панелью, подсказки и горячие клавиши V/P/E/T/M/H.

Сохранение **локальное**, в текущем браузере и origin; для переноса и резервного
хранения скачайте JSON. Статус ошибки хранения не означает успешное сохранение:
можно скачать документ и повторить запись. История Undo относится к текущему
сеансу и не сохраняется между открытиями доски. Clipboard объектов — внутри
текущего редактора; LaTeX можно копировать в системный буфер отдельно.

## Проверки

```sh
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run format:check
```

Playwright в облачной среде использует `/usr/bin/chromium`.
На другой машине установите Chromium и задайте путь через
`PLAYWRIGHT_CHROMIUM_EXECUTABLE`. Тесты сами запускают dev-сервер, если порт 3000
не занят. Запускайте build и e2e последовательно, чтобы не менять `.next`
одновременно. Форматирование: `npm run format`.

## Следующие этапы и ограничения

Следующий шаг MVP 2: подключение реального handwriting/math recognition API
через готовый provider interface. MVP 3: графики, constraints, OCR и голос.
MVP 4: Three.js модели и сечения. MVP 5: серверное хранение, совместная работа,
teacher/student permissions. Сейчас подключён только явно обозначенный demo
flow с фиксированными вариантами; настоящий AI остаётся отдельным подключением.

Рендер разделён на Canvas strokes/shapes и DOM text/math; текст и формулы находятся
поверх Canvas. Полное управление слоями и z-order между этими слоями относится к
следующим этапам. Пока нет PDF/Word экспорта и истории версий.
Математический ввод — LaTeX; визуальный редактор формул будет отдельным улучшением.
Частота 60 FPS и работа на физических Apple Pencil/графических планшетах требуют
измерений на соответствующих устройствах; аппаратная сертификация не заявляется.

История Undo хранится для операций с объектами; навигация по доске и изменение
метаданных урока не входят в неё. На macOS работают сочетания с Cmd.
Presentation Mode включается отдельно. В нём кнопка «На весь экран» включает
настоящий Browser Fullscreen; повторное нажатие или Esc возвращает окно,
сохраняя презентацию. Кнопка «Выйти из презентации» закрывает только презентацию.
Если Fullscreen API недоступен, кнопка скрыта; отказ браузера не мешает работе.
